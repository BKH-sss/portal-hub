넥슨 Open API Key 발급 방법

넥슨 오픈 API의 스타포스 강화 기록 조회는 계정 본인의 '서비스 API 키'가 필요합니다.

  1. 넥슨 오픈 API 개발자 센터 (openapi.nexon.com)에 접속하여 넥슨 계정으로 로그인합니다.
  2. 상단 메뉴의 [내 애플리케이션] ➔ [애플리케이션 등록]을 누릅니다.
  3. 애플리케이션 이름을 입력하고 '서비스 API 키 (Live Key)'를 발급받습니다.
  4. 발급된 키(live_... 로 시작하는 문자열)를 복사하여 상단 입력창에 붙여넣으시면 됩니다.

✨ API 키 없이 테스트하고 싶으신가요?
우측 상단의 [22성 샘플 로드] 버튼을 누르면 즉시 시뮬레이션 데이터를 체험하실 수 있습니다!
