# 🏆 LoL Local Desktop Intelligence Overlay (YOUR.GG Benchmarked)

라이엇 Live Client Data API(`127.0.0.1:2999`)를 활용하여 게임 실행 중 화면 위에 투명 오버레이로 정보를 띄우는 **로컬 데스크톱 인게임 오버레이 앱**입니다.

---

## 🛡️ 라이엇 제3자 개발자 정책 준수 선언
- **⛔ 절대 미지원 (정책 위반)**: 적 챔피언 스킬/스펠(점멸 등) 쿨타임 표시 기능은 완전히 배제되어 있습니다.
- **📊 통계적 추정치 명시**: 라인 상대 복귀 타이밍 등은 "통계적 추정치 / 예상"임을 UI 및 코드에 명확히 표기합니다.
- **🚨 킬 스위치 (Kill Switch)**: `config.py`의 boolean 플래그로 개별 기능을 즉각 켜고 끌 수 있습니다.
- **🖱️ Click-Through**: Windows API를 통해 게임 조작(클릭, 키 입력)을 일체 방해하지 않습니다.

---

## 🌟 구현 기능 (4대 정식 기능)
1. **⚔️ 초반 라인 딜 교환 팁**: 1~4레벨 구간 내 챔피언 vs 상대 챔피언 상성 및 행동 가이드
2. **🚨 상대 핵심 아이템 완성 알림**: 시야 내 적의 전설/신화급 완성 아이템 구매 실시간 알림
3. **⏳ 라인 상대 복귀 타이밍 예측**: 상대 사망 시 리스폰 + 이동 시간 기반 복귀 예상 카운트다운
4. **⏱️ 골드/오브젝트 이벤트 타임라인**: 킬, 드래곤, 전령, 바론, 포탑 파괴 시계열 정리

---

## 🚀 실행 방법
`롤_데스크톱_오버레이_실행.bat`을 더블 클릭하거나 아래 명령어를 실행합니다.
```bash
python desktop_overlay/main.py
```
