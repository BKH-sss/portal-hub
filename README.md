# 🌐 NEXT PULSE - 4차 산업 및 스포츠 정보 허브

실시간 날씨 및 미세먼지, 축구 경기 일정, 4차 산업 및 게임 산업 최신 뉴스를 제공하는 웹 포털 서비스입니다.

## ✨ 주요 기능
- **맨체스터 유나이티드 경기 허브**: 최근 경기 스코어 및 다가오는 경기 일정
- **실시간 날씨 & 미세먼지**: 주요 도시별 기상 예보 및 PM10 / PM2.5 대기질 상태
- **4차 산업 & 게임 산업 피드**: AI, 반도체, 로봇, 게임 업계 실시간 최신 뉴스 브리핑

## 🚀 기술 스택
- **Frontend**: HTML5, Tailwind CSS, JavaScript (Vanilla ES6+)
- **Hosting**: GitHub Pages
- **Automation**: GitHub Actions (2시간 주기 자동 업데이트)
