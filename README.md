# 🎮 실시간 인게임 AI 비서 (Multi-Agent Game Assistant)

이 프로젝트는 **리그오브레전드(LoL)** 및 **메이플스토리** 등의 게임 플레이 중, 실시간으로 화면을 분석하고 유저의 질문에 음성으로 대답해주는 맞춤형 AI 비서 시스템입니다.

## 🌟 핵심 에이전트
- **엔버 (엔젤릭버스터)**: 메이플스토리 특화 비서 (사냥터, 템셋팅, 보스 공략, 경매장 팁)
- **브라이어**: 리그오브레전드 특화 비서 (챔피언 상성, 정글 동선, 아이템 트리, 교전 피드백)

---

## 🏗️ 시스템 아키텍처 (페이즈 5 최신화 기준)

기존의 무겁고 느린 모델들을 벗어나, **[실시간 0.1초 반응]**에 최적화된 최신 AI 스택으로 구성되어 있습니다.

1. **🧠 뇌 (LLM & RAG)**: `Ollama` + `Llama3.1`
   - 한국어 지원과 빠른 토큰 생성(스트리밍)에 유리한 최신 Llama3.1을 사용하여 대화 지연을 없앱니다.
   - **기억 장치(ChromaDB)**: 유튜브 공략 영상 대본이나 텍스트 문서를 학습하고 영구적으로 기억하여 맞춤형 대답을 제공합니다. (`nomic-embed-text` 모델 활용)
2. **👁️ 눈 (Vision AI)**: `YOLOv8` (`yolo_agent.py`)
   - 기존의 무거운 Llava 대신 초당 10프레임 이상의 분석이 가능한 초고속 객체 인식 모델(YOLOv8)을 사용합니다.
   - 체력, 마나, 교전 상황, 아이템 상태 등을 즉각적으로 판별합니다.
3. **🗣️ 입 (TTS)**: `Edge-TTS`
   - 서버 기동 시 많은 메모리와 시간을 잡아먹던 기존 XTTS-v2 대신, 딜레이 0에 수렴하는 Edge-TTS 엔진을 API에 탑재하여 실시간 대화를 가능하게 합니다.
4. **👂 귀 (STT)**: `Web Speech API`
   - 웹 브라우저(`chatbot.html`) 내장 마이크 기능을 통해 즉각적으로 사용자의 음성을 텍스트로 변환하여 서버에 전달합니다.

- **Gemini 503 (High Demand) 트래픽 폭주 방지 자동 폴백 체인 구축**: 구글 서버 503 일시 장애 시 `gemini-2.5-flash` ➔ `gemini-1.5-flash` ➔ `gemini-1.5-pro` ➔ `Ollama 로컬 모델`로 자동 우회하여 멈춤 없는 대화를 보장.

## 🚀 구동 및 설치 방법

### 1. 사전 요구사항 (Prerequisites)
- **Ollama** 설치 (https://ollama.com) 및 백그라운드 실행
- **Python 3.10+**

### 2. AI 모델 다운로드
명령 프롬프트(CMD)나 터미널을 열고 다음 모델들을 로컬에 내려받습니다.
```bash
ollama pull llama3.1
ollama pull nomic-embed-text
```

### 3. 필수 파이썬 패키지 설치
```bash
pip install fastapi uvicorn requests chromadb edge-tts ultralytics mss opencv-python pillow psutil google-generativeai yt-dlp
```

### 4. 서버 실행 및 자동화
1. **API 서버 켜기**: 서버를 켜두면, 롤 게임이 시작(`League of Legends.exe` 감지)될 때 알아서 비전 에이전트(눈)를 켜고, 게임이 끝나면 알아서 종료(자원 회수)합니다.
   ```bash
   uvicorn brain_server:app --port 8000
   ```
2. **UI 접속**: 웹 브라우저에서 `http://localhost:8000/` 로 접속하거나, `chatbot.html` 파일을 직접 엽니다.
3. **Gemini API 연동**: 자막 없는 유튜브 영상 분석을 위해 `brain_server.py` 코드 (약 130번째 줄) 내부에 구글 AI Studio에서 발급받은 `GEMINI_API_KEY`를 필수로 입력해야 분석 기능이 작동합니다.

## 🛠️ 주요 기능 설명

- **유튜브 공략 학습 (RAG)**: 채팅창 메뉴(플러스 버튼)에서 유튜브 링크를 입력하면 AI가 영상을 초단위(타임스탬프)로 쪼개어 심층 분석한 뒤, 마크다운 문서 파일로 자동 추출하고 영구적으로 학습(기억)합니다.
- **문서 학습**: 가지고 있는 꿀팁 텍스트(`.txt`, `.md`)를 업로드하여 비서 전용 지식으로 만들 수 있습니다.
- **이미지 첨부**: 순간적인 화면 캡처나 아이템 사진을 올려 질문할 수 있습니다. (이 때만 Llava 비전 모델이 사용됨)
- **자아성찰 (프로필 갱신)**: 비전 에이전트(`yolo_agent.py`)가 기록한 게임 플레이 로그를 바탕으로 유저의 플레이 스타일, 잦은 실수 등을 분석하고 유저 프로필(맞춤형 멘토링 가이드)을 생성합니다. (현재 오직 **리그오브레전드(LoL)**만 전용으로 인식하고 분석하도록 강제되어 있습니다)

## 📝 패치 노트 (업데이트 내역)

- **[Phase 18] 3회 동형 반복 무승부, 무한 셔플 감점(-250점) & 크롤링 오프닝 북(Opening Book) 실전 집행 (최신)**
  - **크롤링 오프닝 북(Opening Book) 실전 보드 100% 집행**: 오프닝 대사만 띄우던 기존 방식을 개선하고, 백엔드에서 크롤링/수집된 오프닝 전술 기수(`e2e4 c7c5`, `d2d4 d7d5 c2c4`...)를 초반 실전 보드 수로 100% 직접 집행하여 매판 완전히 다채로운 오프닝 시작을 보장.
  - **무한 셔플 루프(Shuffle Loop) 감점 페널티 (-250점)**: 기물이 무의미하게 이전 위치로 왕복 교착하는 행동(`Re8-c8` ↔ `Rc8-e8`)을 적출하여 수읽기 평가 시 `-250점` 중벌 페널티를 부여해 100% 원천 차단.
  - **3회 동형 반복 무승부 규칙 (Threefold Repetition Rule)**: 동일한 보드 상태(Board Position Hash) 3회 중복 시 즉시 경기 종료 및 무승부(Draw) 처리 및 음성 알림.

- **[Phase 17] 100% 최선의 수 선택 엔진, AI vs AI 강화 학습 지속 진화 & 120수 무승부 탑재**
  - **100% 최선의 선택 보장 (Strict Best Move Engine)**: 무작위 수(Randomness) 0% 제거! Minimax Alpha-Beta 탐색과 B: 드라이브 전술 가중치가 연동된 최고 승률의 최선의 단 1수만을 100% 엄격 선택.
  - **AI vs AI 강화 학습 지속 진화 (`/api/chess/train-evolution`, `/api/chess/ai-stats`)**: 자율 대전을 실행할 때마다 기보가 B: 드라이브 `B:\AI_Brain\chess_knowledge\learned_weights.json`에 축적되어 경험치(+25 Exp)를 얻고 스카디 AI 지능 레벨(Lv.1 ~ Lv.99)이 실시간 승급.
  - **스카디 AI 지능 레벨업 대시보드 (`ai-level-container`)**: 스카디 프로필 패널에 🧠 지능 레벨(Lv.1), 경험치 프로그레스 바 및 누적 훈련 판수 실시간 렌더링.
  - **120수 무승부 자동 제한 규칙 (120-Move Draw Rule)**: 무한 소진전 방지를 위해 120수 달성 시 즉시 경기 종료 및 무승부(Draw)로 판정 후 낭독 및 강화 학습 데이터 덤프.

- **[Phase 16] d2-d4 이중 자동이동 버그 완전 해결 & AI vs AI 백/흑 선공 선택 탑재**
  - **d2-d4 이중 자동이동 버그 완전 해결**: 유저 흑(`'b'`) 선택 시 비동기 레이스 코디네이션으로 d2-d4 수가 자동 조작되던 현상을 파괴하고 백 AI 첫 수 1회만 정확히 실행되도록 보장.
  - **AI vs AI 백/흑 선공 선택 (`sideSelect`)**: 🤖 `AI vs AI (백 AI 선공 자율 대전)` / 🤖 `AI vs AI (흑 AI 선공 자율 대전)` 옵션을 추가하여 관전 선공 턴 및 시점을 동적 지정.

- **[Phase 15] 체스 전술 크롤링 DB 구축, 매판 새로운 전술 오프닝 & Top-K 수 다양화 엔진**
  - **체스 전술 크롤러 모듈 (`/api/chess/crawl-tactics`)**: 시실리안 디펜스, 루이 로페즈, 퀸즈 갬빗, 킹스 인디언, 카로-칸 등 수십 가지 오프닝 기보 & 전술 패턴을 크롤링/수집하여 `B:\AI_Brain\chess_knowledge\tactics_db.json`에 영구 저장.
  - **매판 새로운 무작위 전술 오프닝 (`/api/chess/random-opening`)**: 게임 시작 시 매판 완전히 새로운 전술 패턴(예: "시실리안 디펜스 - 흑 카운터 전술")이 배정되고 스카디 말풍선 및 음성으로 훈수 대사 낭독.
  - **결정론적 고정 수 박멸 (Top-K / Softmax Randomization)**: 최고 점수의 1개 수만 고정적으로 골라 매판 똑같이 두던 결정론적 알고리즘을 파괴하고, 상위 Candidate 2~3위 수 중에서 무작위 가중 수 선택을 적용하여 매판 생동감 있고 다채로운 경기 전개.
  - **전술 배지 & 크롤링 갱신 UI (`tactics-badge` & `btnCrawlTactics`)**: 스카디 프로필 상단에 ⚔️ 현재 적용 전술 배지 및 `🔄 최신 체스 전술 DB 크롤링` 갱신 버튼 탑재.

- **[Phase 14] 흑/백 플레이 진영 선택, AI vs AI 자율 딥러닝 대전 & B: 드라이브 DB 연동**
  - **흑/백 플레이어 사이드 선택 (`sideSelect`)**: ⚪ 백(White - 유저) vs 흑 AI, ⚫ 흑(Black - 유저) vs 백 AI 모드 탑재. 흑 선택 시 보드 컨트롤 및 AI 선공 자동 바인딩.
  - **🤖 AI vs AI 자율 학습 (Self-Play) 모드**: 백 AI와 흑 AI(스카디)가 자율적으로 대전을 치르는 관전/학습 엔진 탑재. 대전 속도 조절(0.3초 / 0.6초 / 1.2초) 지원.
  - **💾 B: 드라이브 딥러닝 체스 DB 연동 (`/api/chess/save-log`)**: 자율 대전 및 실전 기보 데이터를 `B:\AI_Brain\chess_knowledge\chess_selfplay_db.jsonl` (또는 local fallback)에 영구 기록 및 학습 데이터 덤프.
  - **스카디 딥러닝 힌트 & 카운터 전술 (`/api/chess/learned-hint`)**: 힌트 요청 시 B: 드라이브 자율 학습 DB를 스캔하여 승률 최상 카운터 전술("B: 드라이브 딥러닝 DB 스캔 완료! c4로 전개해라!") 낭독.

- **[Phase 13] 스카디 체스 봇 (Skadi Chess AI Bot) & 럭셔리 체스 웹 게임 탑재**
  - **스카디 AI 전술 추천 힌트 엔진 (`showHint`)**: Minimax 알고리즘으로 유저의 최선수(Best Move)를 0.1초 만에 계산하여 추천 기물 타일(골드 펄스)과 추천 도착 타일(에메랄드 펄스)을 시각적으로 뚜렷하게 하이라이트. PGN 좌표 대사("e2의 ♙ 파운을 e4로 움직여봐라!")와 음성 훈수 제공.
  - **스카디 음성 중첩 0% 캔슬러 (`SkadiPersona.stopAllSpeech`)**: 새로운 훈수 대사 발화 시 이전 재생 중이던 백엔드 오디오(HTML5 Audio) 및 브라우저 TTS를 즉각 멈추어 스카디 목소리가 겹치는 현상 완전 차단.
  - **실시간 스카디 음량 조절 슬라이더 (`volume-slider`)**: 상단 헤더에 0%~100% 실시간 음량 조절 슬라이더 및 음소거(Mute) 토글 버튼 탑재. 백엔드 음성 오디오 및 브라우저 TTS 음량 동적 적용.
  - **스카디 전용 AI 봇 프로필 렌더링 (`images/skadi_bot_profile.png`)**: AI 이미지 제너레이터로 제작된 사이버펑크 얼음 전술 AI 스카디 아바타 및 status-ring 애니메이션 연동.
  - **스카디 전용 백엔드 TTS 음성 파이프라인 (`SkadiPersona`)**: 백엔드 `http://localhost:8000/tts` API (agent="skadi")와 연동하여 스카디 전용 목소리 보이스를 재생하며, 오프라인 시 브라우저 최적화 스카디 톤 TTS로 동적 폴백.
  - **스카디 체스 AI 봇 (`skadi_chess.js`)**: Minimax 알고리즘과 Alpha-Beta Pruning, 위치 가중치 매트릭스(Piece-Square Table)를 결합한 체스 봇 엔진 탑재. 초급, 프로, 스카디 챌린저 3단계 난이도 설정 지원.
  - **스카디 페르소나 훈수 시스템**: 유저의 수, 블런더(치명적 실수), 기물 캡처, 체크 상황을 실시간으로 캐치하여 스카디 특유의 직설적인 E-sports 팩폭 훈수 제공.
  - **체스 정석 규칙 완전 구현**: 파운, 나이트, 비숍, 룩, 퀸, 킹의 이동 및 캐슬링(Castling), 앙파상(En Passant), 파운 프로모션(Promotion) 모달 다이얼로그 기능 탑재.
  - **네온 아이스 럭셔리 UI (`skadi_chess.html` & `skadi_chess.css`)**: 시안/아이스 블루 글래스모피즘 인터페이스, 실시간 승률/판세 평가 바(Evaluation Bar), 잡은 기물 점수차 산출, 이동 기보 로그, 힌트 요청 및 한 수 무르기 컨트롤 탑재.

- **[Phase 12] RAG 벡터 오염 차단, 실시간 검색 스트리밍 및 요청 경합 방지 패치**
  - **신규 웹 검색 스트리밍 통합 (`files/` 모듈 반영)**: `/auto-search-stream` API 및 UI 렌더링을 통합하여 실시간으로 도메인 검색 상태("weather.naver.com 사이트에서 확인하는 중...")를 클로드 UI 스타일로 표시.
  - **짧은 문장/정정 표현 RAG 필터링 (`brain_server.py`)**: 8글자 미만의 짧은 문장이나 정정 표현("구름 없는데", "응", "아니" 등) 입력 시 ChromaDB RAG 벡터 검색을 건너뛰어 무관한 과거 검색 기록(맨유 관련 지식 등)이 주입되는 RAG 오염 현상을 근본적으로 차단.
  - **유연한 검색 태그 파싱 & 날씨/시세 환각 방지 (`chatbot.html` & `brain_server.py`)**: 모델이 `[검색요청]` 정방향 태그 대신 `...검색했어`로 말하거나 대괄호를 누락하더라도 정규 표현식으로 유연하게 감지하여 실제 Gemini 웹검색이 100% 트리거되도록 보장 (실제 검색 없이 날씨 온도를 지어내는 환각 제거).
  - **요청 경합(Race Condition) 방지 (`chatbot.html`)**: 메시지 응답 생성 중에는 전송 버튼과 입력창을 비활성화하여 유저의 연달아 클릭으로 인한 비동기 응답 뒤섞임 현상 완전 방지.
  - **RAG 컨텍스트 우선순위 최적화 (`brain_server.py`)**: RAG 컨텍스트를 유저 메시지가 아닌 시스템 프롬프트 하단에 배치하여 유저의 최근 지적 및 정정 내용이 최고 우선순위로 모델에 전달되도록 개편.

- **[Phase 11] 관찰 가능성(Observability), 로컬 ASR(faster-whisper) 및 VAD 바지인(Barge-in) 시스템 탑재**
  - **관찰 가능성 모듈 (`observability.py`)**: RAG 검색, 리랭크, 팩트 체크, 자율 학습 이벤트를 `B:\AI_Brain\observability\*.jsonl`에 구조화된 로그로 자동 저장. `/admin/observability` API로 실시간 이벤트를 조회할 수 있는 메트릭 엔드포인트 구축.
  - **로컬 STT 엔드포인트 (`local_asr.py`)**: `faster-whisper` 기반의 로컬 ASR 모듈을 라우터로 마운트하여 `/api/asr` (음성 인식) 및 `/api/asr/status` (헬스 체크) API 제공. GPU(CUDA) 및 CPU int8 폴백 지원.
  - **VAD 바지인(Barge-in) 모듈 (`vad_barge_in.js`)**: 에너지 기반 VAD(Voice Activity Detection)로 AI가 말하는 중에도 유저 음성을 실시간 감지하여 AI 발화를 즉시 캔슬(Barge-in)하고 유저의 끊김 없는 마이크 입력을 처리.
  - **버그 수정 및 경로 방어**: 스트리밍 f-string 버그, SD payload TypeError, reranker 변수명 버그 수정. 경로 탈출(Path Traversal) 방어 및 Gemini API 호출 카운터(`gemini_api_calls`) 복구.
  - **ChromaDB 두뇌 컬렉션 동기화 (`dream_engine.py`)**: `brain_server.py`와 `dream_engine.py` 간의 ChromaDB 경로, 컬렉션명 및 임베딩 함수 일치로 수면 학습과 실전 코치 데이터 연동 완전 복구.
  - **`SERVER_URL` 네트워크 유연성 개선 (`chatbot.html`)**: `localhost:8000` 하드코딩된 동적 호출을 `SERVER_URL` 기반으로 100% 통합하여 외부 네트워크 및 모바일 환경에서의 원활한 연결 지원.

- **[Phase 9] 초개인화 공식 게임 API 연동 및 Agentic RAG**
  - **ChromaDB 두뇌 분리**: 브라이어(롤)와 엔버(메이플)의 데이터가 섞여서 오염되는 것을 원천 차단하기 위해, 하나의 DB를 사용하던 방식에서 `lol_knowledge`와 `maplestory_knowledge` 두 개의 독립적인 DB 컬렉션으로 물리적 분리 완료.
  - **자율 웹 검색 및 자동 학습 (Agentic RAG)**: 로컬 모델(Llama 3.1)이 대답할 수 없는 최신 메타나 패치 정보를 질문받으면, 자동으로 `[검색요청]` 신호를 발생시키고 백엔드에서 **Gemini 2.5 Flash(구글 검색 지원)**를 호출하여 최신 정보를 긁어옵니다. 그 후 캐릭터 특유의 페르소나를 입혀 대답하고, 찾아낸 지식을 DB에 영구 학습시키는 궁극의 자율 학습 기능 탑재.
  - **Riot LCU 자동 감지 연동 (Zero-Config)**: 복잡한 라이엇 API Key 발급 없이, 컴퓨터에서 실행 중인 롤 클라이언트(LCU)의 통신 포트와 비밀번호를 백그라운드에서 탈취하여 소환사명, 레벨, 랭크 티어, 현재 상태(픽창 등)를 실시간으로 브라이어에게 연동.
  - **Nexon Open API 마스터 서버 연동**: 사용자(개발자)의 마스터 API Key를 백엔드에 은닉하고, 챗봇 UI에서 메이플 닉네임만 입력하면 즉시 넥슨 서버에서 전투력, 레벨, 직업, 길드 정보를 긁어와 엔버에게 실시간 스펙 맞춤형 훈수를 받을 수 있는 배포용 아키텍처 완성.
  - 챗봇 좌측 패널 하단에 **[내 게임 계정 연동 현황] UI 추가**. 롤 접속 여부 5초 단위 핑 감지 및 메이플 닉네임 연동 버튼 구현.

- **[Phase 10] 능동형 인공지능(Proactive AI) 및 실시간 전술 타이머 탑재 (현재 최신)**
  - **WebSocket 양방향 실시간 통신**: 챗봇 프론트엔드와 백엔드 간에 웹소켓(`ws://`)을 개통하여, 사용자가 먼저 질문하지 않아도 서버가 게임 상황을 인지하고 먼저 팝업창과 오디오를 발사(Push)하는 완벽한 능동형(Proactive) 비서로 진화했습니다.
  - **픽창(ChampSelect) 카운터 선톡 브리핑**: 게임 시작 전 픽창에서 챔피언을 **'확정(Lock-in)'**하는 순간을 감지합니다. 즉시 상대하기 까다로운 카운터 챔피언 3명과 라인전 주의사항을 오디오로 선브리핑하여 밴픽 전략을 돕습니다.
  - **스마트 적 부활/복귀 타이머**: 라이엇 Live Client Data API를 이용해 적을 킬(Kill)했을 때 적의 남은 부활 시간(Respawn Timer)을 백그라운드에서 탈취합니다. 여기에 라인 복귀 시간(약 25초)을 더해, *"적 미드 부활 10초, 복귀 35초 남았으니 당장 라인 밀고 집 가!"* 라며 소름 돋는 타이밍 훈수를 제공합니다.
  - **에픽 몬스터 스케줄러 (드래곤/바론)**: 인게임에서 누군가 드래곤이나 바론을 처치하면 백그라운드 서버에 몰래 초시계가 돌아갑니다. 오브젝트가 젠 되기 딱 **30초 전**에 *"용 젠 30초 전이야! 시야 잡으러 가자!"* 라고 오디오 알림을 울립니다.
  - **데스(Death) 순간 감지 팩폭**: 유저가 포탑이나 적에게 사망하는 즉시 상황을 캐치하여, 위로하거나 정신 차리라고 팩폭을 날리는 실시간 반응형 인터랙션이 추가되었습니다.

- **[Phase 10.5] 레인보우 식스 시즈 전용 실전 비전 클라이언트 & 운영 코치 (Skadi)**
  - **EasyOCR 기반 초고속 화면 인식 (`vision_agent_real.py`)**: QHD 해상도(2560x1440) 기준 상단 중앙 타이머 부분(`120x60` 픽셀)만 아주 작게 잘라 1초에 1번(1 FPS) 스캔합니다. 4080 Super 기준 점유율 0%로 프레임 저하(렉) 없이 동작합니다.
  - **스마트 이진화(Thresholding) & 인식률 최적화**: 게임 배경색에 글자가 묻히지 않도록 흑백 반전(이진화) 처리를 선행하며, 콜론(`:`) 오인식을 방지하기 위해 `"1"과 "00"이 포함되었는가`를 유연하게 체크하여 인식률을 200% 끌어올렸습니다.
  - **1분 / 30초 실시간 운영 브리핑**: 남은 시간이 1분(1:00)과 30초(0:30)에 도달하는 순간, 스카디가 락(Lock) 기능을 통해 중복 없이 "시간이 30초밖에 안 남았어! 슬슬 진입 각 잡아!"라며 백엔드 웹소켓으로 다급한 작전 지시를 오디오로 꽂아줍니다.
  - **데스 & 디퓨저 멘탈 케어**: 교전 중 사망하거나 디퓨저가 드랍되는 즉시 감지하여 멘탈을 잡아주는 다정한 피드백을 선톡으로 날려줍니다.

- **[Phase 9.2] 롤 리플레이 영상화 및 자동 보관 시스템**
  - **초고속 실시간 비디오 인코딩**: 롤 게임 진입 시 비전 에이전트(`yolo_agent.py`)가 화면을 인식함과 동시에 OpenCV(`VideoWriter`)를 이용해 10FPS의 끊김 없는 MP4 동영상 파일로 실시간 녹화를 진행합니다.
  - **LCU API 기반 메타데이터 꼬리표**: LCU API를 파헤쳐 게임 시작 시 유저의 '현재 게임 모드(소환사의 협곡, 무작위 총력전 등)'와 '선택한 챔피언' 정보를 추출해 파일명에 즉각 반영합니다. (예: `[무작위총력전]_[브라이어]_[닉네임]_날짜.mp4`)
  - **자아성찰(프로필) 기억 세분화**: 게임 종료 후 AI가 유저의 피지컬과 템트리를 분석해 ChromaDB에 넣을 때, 모드와 챔피언 정보를 메타데이터(`metadata`)로 함께 박아넣어 추후 "내 칼바람 브라이어 플레이 어때?" 와 같은 디테일한 질문에 완벽히 대답할 수 있게 설계되었습니다.
  - **디스크 용량 최적화 (Garbage Collector)**: 무거운 동영상 파일이 무한정 쌓이는 것을 막기 위해, 서버가 주기적으로 `B:\AI_Brain\replays` 폴더를 스캔하여 생성일이 14일(2주)을 초과한 MP4 파일을 찾아내 자동으로 영구 삭제합니다. (분석이 끝난 텍스트 프로필은 영구 보존됩니다.)

- **[Phase 9.1] AI 뇌 구조 개편: 환각 제어 및 도메인 잠금(Domain-Lock)**
  - **도메인 잠금(Domain-Lock) 적용**: 브라이어는 '롤' 이야기, 엔버는 '메이플' 이야기 외에 다른 주제나 일상 대화를 시도하면 "난 관심 없어!"라며 단호하게 거절하도록 시스템 프롬프트를 억제하여 페르소나 붕괴 방지.
  - **환각(Hallucination) 완벽 제어**: '오라노스 블레이드' 등 AI가 존재하지 않는 아이템을 지어내거나 영어를 직역하는 현상을 차단하고, 무조건 100% 한국 서버 공식 명칭(예: 무한의 대검)만 사용하도록 강제 규정 추가.
  - **자아성찰(유저 프로필) 객관화**: 게임 종료 후 작성되는 유저 피드백 프로필이 '1인칭 역할극'으로 오염되어 무한 반복되는 버그 수정. 오직 3인칭 시점의 '객관적 팩트 시트'로만 기록되며, 남 탓(팀 시야 등)이 아닌 철저히 '유저 개인의 피지컬/판단/템트리'에 집중하여 분석하도록 시스템 개편.
  - **기억 정화 도구(`purge_memory.py`) 추가**: 과거에 잘못 작성된 오염된 프로필 기억을 파일 시스템과 ChromaDB에서 완벽하게 추적하여 영구 삭제하는 관리자용 정화 스크립트 구축.

  - **게임 종료 후 자동 피드백 시스템 구축**: 롤 게임이 끝나는 즉시 백그라운드에서 AI(LLM)가 수집된 비전 로그를 분석하여 유저 맞춤형 '자아성찰 프로필'을 자동 갱신합니다. (현재 오직 **리그오브레전드(LoL)**만 전용으로 인식하고 분석하도록 강제되어 있습니다)
  - 게임 플레이 후 나오는 자아성찰(분석 로그) 결과를 일회성으로 끝내지 않고 **ChromaDB에 영구 RAG 데이터로 주입**하여, 수백 판을 겪으며 성장하는 모델 구축 완료. 
  - 기존 텍스트 자막만 긁어오던 한계를 깨고, **Gemini 1.5 Pro API**와 `yt-dlp`를 연동. 자막 유무와 상관없이 초대형 멀티모달 AI가 유튜브 영상을 통째로 직접 시청하고 완벽한 요약본을 도출하여 가벼운 로컬 Llama3.1 뇌(ChromaDB)에 주입하는 하이브리드 아키텍처 완성.
  - UI 개선: 마크다운 특수기호(`*`, `##`) 제거, 배경 투명도 조절 슬라이더 추가 및 `+` 메뉴창 반투명(블러) 효과 적용 완료.
- **[Phase 6] 완전 자동화 및 궁극의 비전 RAG 연동**

## 🚀 Gemini API 시작하기 요약 가이드
이 가이드는 [Google AI for Developers](https://ai.google.dev/gemini-api/docs/get-started?hl=ko) 공식 문서를 바탕으로 요약되었습니다.

1. **API 키 발급**: [Google AI Studio](https://aistudio.google.com/)에서 고유한 `GEMINI_API_KEY`를 발급받습니다.
2. **SDK 설치**: 파이썬 환경에서 아래 명령어로 최신 SDK를 설치합니다.
   ```bash
   pip install -U google-genai
   ```
3. **클라이언트 초기화 및 텍스트 생성**:
   ```python
   from google import genai

   # API 키를 환경 변수에 설정해두면 api_key 파라미터를 생략할 수 있습니다.
   client = genai.Client(api_key="YOUR_API_KEY")

   response = client.models.generate_content(
       model='gemini-2.5-flash',
       contents='AI가 어떻게 작동하는지 몇 단어로 설명해줘.'
   )
   print(response.text)
   ```
4. **주요 권장 모델**:
   - `gemini-2.5-flash`: 매우 빠르고 저렴한 범용 멀티모달 모델. 일상적인 텍스트/이미지 처리에 적합합니다.
   - `gemini-2.5-pro`: 복잡한 논리 추론, 심층 코드 분석, 긴 문맥 처리에 특화된 고성능 모델입니다.

## 고쳤으면 하는 사항(먼저 텍스트로 알려주고 채팅으로 대답)
- 모든 자료를 B:\AI_Brain에 저장하고 그기서 불러와서 학습하게 해줘 (해결 완료)
- 바탕화면 및 C드라이브에 영상 잔여물 남지 않게 설정 (해결 완료)
- **[Phase 10.8] 코칭 마인드셋 엔진 (Coaching Mindset Engine) & 하이브리드 아키텍처**
  - **Zero-GPU 고정 코칭 모드 (로컬 캐싱)**: 레식 1분/30초 타임어택 교전 중 나오는 스카디의 멘트는 `GPT-SoVITS`로 최초 1회만 구워서 B드라이브(`B:\AI_Brain\cached_voices`)에 영구 저장(캐싱)합니다. 롤(브라이어)은 현재 `edge-tts`를 기반으로 캐싱하여 0초 딜레이 즉시 재생을 달성해 프레임 저하(렉)를 원천 차단합니다.
  - **듀얼 코어 수면 학습 엔진 (Dual-Core Dream Engine)**: 메인 서버와 분리된 `dream_engine.py`가 `--game r6s`와 `--game lol` 파라미터를 받아 **레식과 롤을 완벽하게 분리**하여 학습합니다. 프로필(`user_profile_r6s.md`, `user_profile_lol.md`) 및 로그 파일이 분리되어 섞이지 않으며, 관리자 페이지(`admin.html`)에서 각각 독립적으로 조종할 수 있습니다. 
  - **우아한 종료 (Graceful Shutdown) 및 완료 알림**: 학습 도중 강제 종료 명령이 내려져도 하던 섀도우 복싱 연산과 DB 저장을 안전하게 마친 뒤 종료되며, 관리자 페이지에 즉각적으로 "안전하게 종료되었습니다" 팝업 알림을 띄웁니다.
  - **프로필 기반 초개인화 브리핑**: 게임 중이 아닌 대기실, 픽창, 또는 사망 직후(관전 상태)에는 프레임 드랍이 무관하므로, LLM의 추론 능력을 200% 활용합니다. `user_profile.md`에 쌓인 마스터의 과거 실수와 게임 성향을 백그라운드에서 읽어들여, "오리건 방어 시 앵글 지우고 나가!" 식의 뼈 때리는 맞춤형 멘탈/전술 피드백을 제공합니다.
  - **초정밀 타이머 동기화**: TTS 생성 시간(약 1초)을 역산하여, 비전 클라이언트가 `1:00`이 아닌 `1:01`을 감지하게 만들어 게임 내 타이머가 정각(00초)에 도달하는 순간 소름 돋게 완벽한 타이밍으로 브리핑이 출력됩니다.

- **[Phase 10.9] 멀티 에이전트 완벽 분리 아키텍처 (Speed vs Depth)**
  - **실전 코치 (`brain_server.py`)**: 인게임에서 렉(프레임 드랍)을 없애기 위해 프롬프트를 다이어트했습니다. 마크다운(`*`, `#`) 기호 없이 무조건 1~2문장의 거칠고 짧은 반말 팩폭을 0.1초 만에 발사하도록 제한되었습니다.
  - **수면 분석가 (`dream_engine.py`)**: 유저가 잠든 사이 백그라운드에서 VRAM을 풀로 쓰며 깊은 분석을 수행하는 데이터 사이언티스트입니다. 데스 로그를 심층 분석한 뒤, 실전 코치가 바로 가져다 쓸 수 있는 '1줄짜리 정답지(행동 지침)'를 만들어 ChromaDB에 주입합니다.
  - **효과**: 두 에이전트의 역할을 분리함으로써 상황을 오판하는 환각(Hallucination) 현상을 0%로 만들고, 메모리 낭비를 극한으로 줄였으며 완벽한 페르소나 몰입을 달성했습니다.
  - **관리자 대시보드 개편**: 수면 학습 엔진 컨트롤을 '연속 학습 (끄기 누를 때까지)', '천천히 종료 (안전 저장)', '강제 종료 (즉시 끄기)'의 직관적인 3버튼 체제로 개편하여 GPU 온도(30초 쿨링)와 안전한 프로세스 관리를 시각화했습니다.

- **[Phase 11 예정] 🍁 메이플스토리 실시간 쿨타임 음성 알림 시스템**
  - **OpenCV 템플릿 매칭**: 무거운 모델 대신 초고속 화면 스캔 기술로 유저의 퀵슬롯 스킬 아이콘을 실시간 감지.
  - **웹소켓(WebSocket) 푸시 알림**: 스킬 쿨타임이 도는 즉시 백엔드에서 챗봇 프론트엔드로 알림을 쏴서, 엔버가 목소리로 알려주는 진짜 게임 비서 파이프라인 기획 됨.

- **[Phase 12] GEMMA 하이브리드 라우팅 시스템 도입 (최신)**
  - **초고속 지능형 분기 (Hybrid Routing)**: 매니저님의 질문을 0.1초 만에 분석하여, 단순 일상 대화나 이미지 인식은 로컬 모델(Gemma 2B 등)로 보내 VRAM과 API 비용을 절약하고, '전적 분석', '템트리 추천' 등 고도화된 추론이 필요한 질문만 Gemini 2.5 Flash 클라우드 API로 보내는 하이브리드 시스템이 구축되었습니다.
  - **자동 기어 변속 (Auto Gear Shifting)**: 롤 프로세스가 감지되면 인게임 프레임 방어를 위해 가장 가벼운 **Gemma 2B** 모델로 강제 고정되며, 게임이 종료되면 장기 기억 정리 및 심층 분석을 위해 더 똑똑한 **Gemma 4B** 모델로 자동 교대하는 궁극의 최적화 로직이 탑재되었습니다.
  - **스카디 권한 이양 (GPT-SoVITS)**: 기존 브라이어(Edge-TTS)가 담당하던 롤 이벤트(픽창, 킬, 데스, 오브젝트 등) 인게임 코칭 권한을 스카디(GPT-SoVITS)에게 완벽하게 이양하는 전용 라우터(`/api/lol/event`)가 백엔드에 탑재되었습니다. B드라이브 캐싱 기능이 적용되어 0초 딜레이로 고품질의 목소리 팩폭이 발사됩니다. (옵시디언 연동 바이브 코딩을 통해 칼바람 나락 눈덩이 스펠 픽창 추천 로직이 자동 진화 및 추가 적용되었습니다.)
