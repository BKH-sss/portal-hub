# 🌊 스카디(Skadi) 24/7 지능형 일상 어시스턴트 디스코드 봇 (Bot A)

> **Google Gemini 2.5/3.5, Claude 3.7 Sonnet, OpenAI GPT-4o, Ollama** 다형성 LLM 엔진과 영구 장기 기억(Long-term Memory), 구글 캘린더/스케줄러, 주식 퀀트 리포트, S급 Stable Diffusion 화가(Painter)가 결합된 **24시간 365일 무중단 일상 AI 비서**입니다.

---

## 🌟 주요 기능 (Core Capabilities)

1. **💬 5대 페르소나 및 멀티 LLM 오케스트레이션**:
   - `보카디`: 명일방주 보카디 특유의 신비롭고 애틋하며 다정한 반말 인격
   - `비서`: 똑똑하고 세심하며 핵심을 짚어주는 쿨한 지능형 비서 인격
   - `주식`: 직설적 팩폭과 안전한 분할매수를 권고하는 천재 퀀트 트레이더
   - `화가`: 사용자의 요청을 Stable Diffusion 고품질 프롬프트로 변환 및 렌더링
   - `레식`: 레인보우 식스 시즈 전술 및 맵 브리핑
2. **📅 구글 캘린더 & iCal 연동 일정/할 일(Todo) 매니저**:
   - Google Calendar iCal 비공개 URL 동기화 및 15분 주기 자동 백그라운드 갱신
   - 일정 조회/추가/삭제 (`!일정`, `!일정추가`, `!일정삭제`)
   - 진행 중인 체크리스트 할 일 관리 (`!할일`, `!할일추가`, `!할일완료`, `!할일삭제`)
3. **🌅 매일 아침 8시 자율 모닝 브리핑**:
   - 실시간 날씨, 미세먼지(PM10)/초미세먼지(PM2.5) 등급
   - 오늘 하루의 캘린더 스케줄 & 마감 임박 할 일
   - 마스터 맞춤 3대 관심 테마 최신 뉴스 2줄 요약
4. **📈 국내 & 미국 증시 3개년 성장주 퀀트 브리핑**:
   - 부채비율 120% 이하 + 3개년 자산 성장 기업 대상 실시간 랭킹 산출
   - 국내 장 마감(오후 3시 40분) & 뉴욕 장 마감(오전 6시 30분) 자동 정기 브리핑
5. **🎨 S급 Stable Diffusion AI 화가 연동**:
   - `!그림 <프롬프트>` 입력 시 실시간 로컬/원격 WebUI AI 이미지 자동 렌더링
6. **🧠 영구 장기 기억 (Long-term Fact Memory)**:
   - 마스터와의 중요한 대화 내용 및 프로필을 SQLite DB에 영구 학습
7. **🌐 Render 클라우드 24/7 포트 바인딩 헬스체크 웹 서버**:
   - `PORT` 환경변수 자동 감지 및 10분 주기 자체 핑으로 무료 티어 절전 방지

## 🚀 빠른 시작 (Quick Start)

### 1단계: 토큰 설정
- 환경 변수 등록 (권장):
  ```bash
  export SKADI_BOT_TOKEN="your_discord_bot_token_here"
  # 또는
  export DISCORD_BOT_TOKEN="your_discord_bot_token_here"
  ```
- 또는 `discord_config.json`의 `"bot_token"` 항목에 토큰 입력

### 2단계: 패키지 설치
```bash
pip install -r requirements.txt
```

### 3단계: 봇 실행
- **Windows**: `디스코드_스카디_실행.bat` 더블 클릭
- **Linux/Render**:
  ```bash
  python discord_skadi_bot.py
  ```

## 🛠️ 주요 명령어 (Commands)

| 카테고리 | 명령어 | 설명 |
| :--- | :--- | :--- |
| **도움말** | `!도움말` (`!help`, `!명령어`) | 전체 명령어 목록 및 사용 가이드 카드 출력 |
| **일정 관리** | `!일정 [날짜]` | 오늘 또는 특정일(YYYY-MM-DD) 캘린더 일정 조회 |
| | `!일정추가 <일시> <제목>` | 새 일정 등록 (예: `!일정추가 2026-09-10 15:00 팀 회의`) |
| | `!일정삭제 <ID>` | 일정 삭제 |
| | `!캘린더연동 <iCal URL>` | 구글 캘린더 비공개 iCal 주소 연동 |
| **할 일(Todo)** | `!할일` (`!todos`) | 진행 중인 할 일 체크리스트 확인 |
| | `!할일추가 <내용>` | 새 할 일 등록 (예: `!할일추가 [긴급] 보고서 제출`) |
| | `!할일완료 <ID>` | 할 일 완료/미완료 토글 |
| | `!할일삭제 <ID>` | 할 일 항목 삭제 |
| **브리핑** | `!모닝브리핑` (`!브리핑`) | 날씨, 미세먼지, 오늘의 일정 & 테마 뉴스 브리핑 즉각 호출 |
| | `!주식 [국내/미국]` | 3개년 자산성장성 & 부채비율 120% 이하 우량주 퀀트 리포트 |

| | `!기억목록` | 스카디가 기억하는 프로필 및 기억 목록 조회 |
| | `!기억삭제 <ID>` | 특정 기억 삭제 |
| **채널/대화** | `!채널지정` | 현재 채널을 멘션 없이 상시 대화 채널로 설정 |
| | `!채널해제` | 상시 대화 채널 해제 |
| | `!청소 [개수]` | 최근 메시지 대량 삭제 (기본 10개) |
| | `!리셋` | 현재 채널의 최근 대화 문맥 초기화 |

## 🔒 보안 및 정책 준수 (Security & Privacy)

- **민감정보 보호**: 구글 캘린더 비공개 iCal URL은 화면 및 로그 출력 시 `https://calendar.google.com/***` 형태로 자동 마스킹 처리됩니다.
- **Riot 제3자 정책 격리**: LoL 관련 실시간 인게임 개입 모듈은 Bot A에서 완전히 제거되었으며, 별도의 전용 봇(`discord_lol_bot.py`)으로 완전 격리 운영됩니다.
